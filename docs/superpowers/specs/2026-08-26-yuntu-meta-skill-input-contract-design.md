# 云图元技能入口契约设计

## 目标

参考 `yuntu-industry-content-rankings-analysis` 的技能入口结构，为 `yuntu-meta-skill` 补充清晰、可复制的 `description`、`argument_hint` 和 `metadata.pre_input`，并让正文输入说明与运行时校验契约一致。

## 范围

- 更新 `SKILL.md` 的 YAML frontmatter：补充 `argument_hint` 与 `metadata.pre_input`。
- 重写“输入”章节，使自然语言入口明确生成 `QuerySpec` 和 `HighlightSpec` 两份配置。
- 在入口引导中表达周期、筛选、榜单指标、详情素材数、封面及高光帧指标选择、策略/帧数。
- 不把 `candidate_top_n` 暴露给使用者；候选池继续由实现固定为 1000。
- 不改变 Python 脚本、JSON schema、采集命令、恢复逻辑或产物路径。

## 入口契约

`description` 说明该技能只负责巨量云图榜单、秒级详情和高光帧资产，不生成分析报告。`argument_hint` 提示使用者填写行业、周期、榜单指标、详情素材数、筛选条件和高光帧设置。

`metadata.pre_input` 使用单条自然语言模板，要求或引导以下字段：

- 行业：必填。
- 时间周期：近 7 天、近 30 天或自定义起止日期；默认近 7 天。
- 榜单指标：曝光量、CTR、互动率或完播率 Top1000；必填。
- 详情素材数：正整数，默认 10，范围不超过 1000。
- 年龄、性别、八大人群：可选，留空表示不过滤。
- 品牌范围：全行业，或指定 3 至 10 个品牌。
- 封面：是否保留，必填。
- 高光指标可从点赞、流失、点击、互动、评论五项中选择至少一项；每个已选指标分别选择 `local_peaks` 或 `top_values`，并给出正整数帧数。

模板必须说明自定义日期为闭区间；候选池是实现内部固定值，不出现在用户输入模板中。

## 正文同步规则

正文输入章节以结构化字段列出默认值、可选项和非法输入行为：筛选项空值不传给 RPA；未知字段、未知策略、缺少任一高光维度或非正整数帧数直接拒绝。继续保留“双入口使用同一解析器、解析成功立即落盘并执行”的行为。

## 非目标

- 不增加分析、报告、模型洞察或浏览器视觉验收。
- 不调整连接器、平台凭证、采集并发、重试或状态语义。

## 验收标准

1. frontmatter 可被 YAML 解析，包含 `name`、`description`、`argument_hint` 和 `metadata.pre_input`。
2. `pre_input` 不出现 `candidate_top_n` 或“候选池”字段。
3. 五项可选高光指标、两种策略、帧数要求和封面设置均有明确引导，并允许只配置其中至少一项。
4. 正文说明与 `scripts/config_specs.py` 中的字段和默认值一致。
5. 现有 Python 测试保持通过。
